# DDS model

The XML model defines the domains, topics, participants, and endpoints shared by the demo applications. The types themselves come from [IDL](../idl/MedTech.idl); QoS profiles are defined [separately](../qos/README.md).

| To understand | Start here |
| --- | --- |
| Load XML, register generated types, create and find entities | [XML application creation workflow](DDS_XML_MODEL.md) |
| Domains, registered types, and topics | [Domain library](DOMAINS.md) and [DomainLibrary.xml](DomainLibrary.xml) |
| Participants, endpoints, and filters | [Participant library](PARTICIPANTS.md) and [ParticipantLibrary.xml](ParticipantLibrary.xml) |

For the architectural overview, see the [DDS contract](../README.md#dds-contract).
